### Added

- **Reflow converts a scanned PDF into a real EPUB, with an AI model rebuilding the structure and never the words.** A PDF book now offers "Reflow this PDF with AI…" on its book page, beside Convert. The app reads the PDF itself first and only sends a page to a model when its layout cannot be settled deterministically, so most pages cost nothing. Before anything is sent you are shown what is in the PDF, what the whole book will cost at each model, and a cap the conversion stops at; the conversion starts only once you agree to a figure. Every page the model returns is checked word by word against the page as printed, and a page that has gained, lost or altered a word is refused and keeps the text read straight out of the PDF. The finished EPUB carries a report page saying how many pages were sent, how many were accepted, and what was spent.
- **Reflow can convert a short sample first, so an expensive book can be judged before it is bought.** A sample is downloaded as an EPUB and adds nothing to the library; if it reads well, the whole book is one button away.
- **A Reflow conversion that stops early tells you which way it stopped.** Three endings leave you holding a file: the book was converted, it reached the cap you set, or the model service stopped answering partway through. The job names the one that happened and says what it means — the pages converted before the stop are in the file, the rest kept the text read straight out of the PDF, and starting it again re-uses every page that was accepted rather than paying for it a second time.
- **A footnote in a Reflow EPUB stays a footnote.** Every note opens where it is called, in the popup a reader expects, and the number at the head of the note takes you back to the sentence — on the pages the model rewrote as well as the pages it did not.
- **The EPUB Reflow writes opens everywhere, and every link in it goes somewhere.** The whole 698-page acceptance book and both model-reviewed samples pass epubcheck 5.2.1 with no errors and no warnings, and all 2,262 internal links land on something that is in the book.
- **The contents of a Reflow EPUB reads as a table of contents and not as scanner noise.** A part of a book that carries no heading of its own — the matter in front of the first chapter, or the tail of an index long enough to be split across several files — used to be listed under its own first six words, so a scanned frontispiece opened the contents as “, ill .ts ?” and every part of the index was listed under a different stray entry. Such a part is now named for where it is: “Page 1”, or “INDEX (pages 684–696)” for the chapter it continues.
- **A Reflow book's report page counts the footnotes it repaired, not the numbers they happen to carry.** A book restarts its footnote numbering every chapter, so counting the distinct numbers the conversion read back off the scan counted one repair for every page that lost the same number. On the 698-page acceptance book that turned 123 repaired markers into “73” and left 44 footnotes listed as having no marker anywhere when the marker is in the book. Where the page can only print some of the numbers it now says how many more there are, rather than printing eight beside a count of seventy-three.
- **A Reflow book says when a picture or a footnote link did not survive the conversion.** Two things only the EPUB writer can see — a footnote marker whose note is not in the finished book, and an illustration it could not cut out of the PDF — were counted and then discarded. They now appear under “What could not be placed” on the report page, and in the conversion's JSON sidecar, beside everything else the conversion could not do.
- **A table's column heads no longer take a section out of its chapter.** Type set as large as a chapter title is kept out of the contents by asking what scanner debris looks like rather than what a heading looks like, and the test for debris only knew about single stray characters. A header row that came back as “Day Night I' J/ / 0” cleared it, became a chapter break, and stood in the contents in place of the section printed below it. Debris with a letter stuck to it now counts as debris; initials in a name still count as words.
- **The price a Reflow book is quoted is always this version's price.** Working out what a book will cost takes seconds of reading the PDF, so the answer is kept and re-used — and it was kept against the PDF alone. A file does not change when the app is upgraded or when the model prices are re-measured, so a book priced before either one went on being quoted at the old figure, which is the figure the consent line asks you to agree to. The kept answer now belongs to the converter and the price table that produced it, and a book is priced again when either changes.
- **A Reflow estimate says so when its page count is an estimate.** Working out how many pages will need a model means running the real deterministic pass, which takes seconds, so it is run over forty pages spread through the book and their routed share is scaled to the rest. On the 698-page acceptance book that projects 384 where the whole book routes 425, and the projection was shown as though it had been counted. A book longer than that sample is now quoted "about 384 (55%)" and told what the figure was worked out from; a book short enough to be read end to end is quoted no hedge, because for it the count is a count.
- **The line you agree to before a Reflow conversion names the money that can actually be spent.** The sentence beside the checkbox quoted the estimate, while what binds a conversion is the cap in "Stop after spending" — which starts a quarter above the estimate on purpose, so a book that runs dearer than its sample finishes instead of stopping just short. Agreeing to "up to $0.89" therefore authorised $1.11, or as much as the administrator's ceiling if the cap was raised afterwards, and raising it did not ask again. The sentence now names the cap, and changing the cap asks for your agreement again.
- **A finished Reflow conversion counts the pages it sent to a model, not the pages it looked at.** Starting a conversion again re-uses every page an earlier run had accepted, and those pages are never sent anywhere — the ledger has always kept them apart, and the card that reports the job did not. A run that sent 210 pages and replayed 212 said it had sent 422, two lines above saying it had reused 212 of them. The card now says what was bought, what was replayed, and what share of everything it reviewed was the model's.
- **A Reflow conversion counts what an answer it could not use had already cost.** A model that replies in prose instead of markup, or runs into the token ceiling half way through a page, has still been paid — the provider billed for the tokens it wrote, and only the answer was worthless. Those pages were written into the job's ledger at $0.00, which is the number the cap stops a conversion at and the number the finished job reports, so the charge reached neither: on the acceptance book 42 pages across four conversions were billed and recorded as free, and a book that answered that way throughout would have spent its way past a ceiling that never moved. A page the provider answered now carries what it cost whatever came back; a page the provider refused outright still costs nothing.
- **The Docker image can read a scanned page itself.** Reflow recognises picture-only and damaged pages with Tesseract, and the image now carries it with its English and page-orientation data (the `tesseract-ocr`, `tesseract-ocr-eng` and `tesseract-ocr-osd` packages). Without it every such page stayed a picture of the page in the finished book. An installation without Tesseract still converts; those pages keep the picture, as before. To recognise more languages, point `TESSDATA_PREFIX` at a folder holding their data files (see `examples/.env.example`).
- **A sample of a long scan reads the front of the book, not all of it.** A 20-page sample of a 3,000-page scan used to read and recognise all 3,000 pages before choosing twenty. It now reads at most the first 61, however long the PDF is, and its card says how many of the PDF's pages it read ("61 of 3000").
- **An administrator decides how long and how large a PDF Reflow will take on.** Two settings in Basic Configuration, next to Reflow's spending cap: pages per conversion (2,000 by default) and PDF size per conversion (500 MB by default). A PDF over either one is refused before any work is done on it — when it is priced, and again before a conversion is queued — with a message giving its length or size and the limit. A conversion queued before a limit was lowered is checked again before it reads a page.
- **Converting a long scan no longer takes memory in proportion to its length.** Each scanned page carries its original image into the book as evidence — about 1.45 MB of JPEG for a letter page — and the converter held every one until the last page was done, so a 2,000-page scan needed gigabytes before a byte reached the disk. Each image is now written into the EPUB as it is made. Measured on a 120-page test scan, the memory the conversion holds while writing the book fell from 180 MB to 7 MB, and it no longer grows with the number of pages. A conversion that stops part way — cancelled, or out of disk — leaves no half-written file behind.
- **Reflow's working files no longer grow without end.** Everything Reflow keeps so that it never does the same work twice — recognised pages, prices, model answers — and the samples, job records and locks it writes all stayed forever. A daily housekeeping task on the existing scheduler now removes what has outlived its kind (samples after 7 days, prices after 30, recognised pages after 60, model answers after 180, the history of a job that spent nothing and filed nothing after a year) and, oldest first, what takes a kind past its size limit. It never removes a job that is still running, a job's record of money spent or held, the records behind an EPUB filed in the library, or the sample of a job still in progress. A job whose sample has been removed says so, and how to make another, instead of just losing its download.
- **No single Reflow request can hold up everyone else.** Opening the Reflow page, pricing a book and starting a conversion each read the whole PDF to identify it on the web server's request loop, so a large scan froze the app for every other user for seconds at a time; that work now runs beside the loop and is remembered until the file changes. Preparing a detailed quote for model review now stops after 30 minutes, taking its OCR with it — the pages it recognised are kept, so preparing again continues where it stopped — and up to four more wait in line, one per person, each told how many are ahead of it, where before everyone else was turned away for as long as one ran.
- **Reflow can file its EPUB into more kinds of library.** Replacing an existing EPUB failed on every SMB, FUSE, rclone and FAT mount, because they refuse the hard link the backup was taken with; the backup is now an exact, verified copy there. A library whose root folder is a symbolic link (`/books` pointing at a NAS mount) refused every whole-book conversion; the root's link is now followed, and nothing below it is. A conversion interrupted while filing no longer leaves a hidden `.reflow-*` folder in the book's directory: recovery removes it, and a conflict that still stands on a later pass is moved, with a manifest of what it held, into Reflow's own data folder.
- **An administrator can use Reflow.** The server accepted a conversion only from an account with the edit permission, so an administrator without it could replace a book's EPUB by hand but not with Reflow. Reflow now accepts the same accounts as every other way of editing a book, and offers its link to exactly those.
- **A Reflow EPUB can no longer carry markup its safety check did not see.** A page that spelled a character with an upper-case entity such as `&QUOT;` was checked as text and then written as markup, which let it carry an event handler, a style or a remote image into the book. The check now reads exactly the bytes that are written, and every finished EPUB is checked once more — only elements the converter writes, no event handlers, no link or image leading out of the book — before it is filed.
- **A Reflow EPUB does not carry what its conversion cost.** The report page inside the book leaves the cost out unless the conversion was set to show it, but the record beside it (`META-INF/reflow.json`) carried the spend, the cap, the token counts and the bill per model regardless. The record now follows the page.
- **The process that prepares a Reflow quote starts without the server's secrets.** It inherited the web server's whole environment, including any model-provider key and database or mail credentials. It now gets only the search path, the locale and Tesseract's settings, and cannot be made to load modules from outside the app.
