## 1. Mutation integrity

Implemented in prepare_mutation/apply_mutation and the isolated phase's mutation
argument: exactly one nonempty byte anchor, changed replacement bytes, stale
source refusal, byte-preserving application after scrub and before preflight.
The no-op is refused before even the provenance pytest probe is launched.

Already covered for the OLD execution route: tests/unit/test_mutation_harness.py:452
(test_a_stale_anchor_is_an_error_never_a_verdict) and :468
(test_an_ambiguous_anchor_is_also_an_error). Those do not substitute for the new
isolated API tests. Existing scrub ordering is covered at :301
(test_sweep_scrubs_after_cleanup_and_again_before_each_phase).

New check tests: test_integrity_refuses_invalid_plan_before_execution and
 test_integrity_preserves_bytes_and_refuses_stale_or_noop_application.
A permissive implementation was executed first; all five cases failed by not
raising IsolationError. It was then replaced with the guards.

Command (retries 0, no maxfail):
```sh
"$ROOT/repo/.venv/bin/python" -m pytest tests/unit/test_mutation_harness.py -k integrity -q -o addopts='' -p no:rerunfailures -p no:flaky --tb=short
```
