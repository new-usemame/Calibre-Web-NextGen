# Filtered book-list downloads (#1059)

The product decision is a complete matching list, rather than only cards currently loaded: CSV carries eight metadata columns and TXT is a one-book-per-line title/author reading list. The issue's later CSV/TXT scope avoids adding an XLSX dependency. Supported catalog/search, submitted Advanced Search, manual/smart shelves and Global Library reuse current visibility and access rules. Discover/Hot samples and Classic custom-column or synthetic None categories have no misleading broader-list fallback; Advanced Search is the recovery for the latter filters.

The endpoint is read-only, authenticated and protected by the existing CSRF/origin middleware. It refuses over 100,000 matches before attachment headers, uses bounded batches and a 1 MiB temporary spool, closes incomplete output and rejects detected result-count changes. Formula-like CSV cells become text; normal CSV quoting preserves Unicode, commas and embedded lines. TXT flattens line breaks. Responses are private/no-store and vary on Cookie and Authorization. Signed, account-bound Classic Advanced Search snapshots preserve the criteria visible in the originating tab for 24 hours and recheck current visibility on use.

- Independent review caught Classic cross-tab mutable criteria, a missing shelf action, materialized Classic ordering, enabled controls before script binding and a default Classic help-text contrast failure. Each was corrected. Holding the real action script gave a seen-red enabled-button failure; the final image keeps both controls disabled until bound. The help text now inherits the actual theme body color. Exact final-image desktop/mobile checks in both Classic palettes reported zero scoped Axe violations and successful Tab/Enter or touch CSV downloads with controls at least 44px tall.
- Initial focused backend/catalog/hidden-book/localization/translation checks: **146 passed, 1 skipped**. After rebasing the search helper onto the current boolean-restriction implementation, export/API/hidden-book/localization checks passed **115 tests, 1 skipped**, and the restriction/admin/OPDS packet passed **23 tests**. TypeScript, E2E typechecking and **192 frontend unit checks** passed during implementation.
- Final whole-image browser packet on the rebased source: **21 passed in 23.4 seconds** at desktop and phone width, including committed request failure/retry, account/list-change cancellation with no late file, held-script loading and cross-tab regressions. Actual downloads compared every title/order to paginated API results while the initial page was deliberately smaller than the matching list. Other actual cases covered both interfaces' CSV/TXT downloads, private shelf membership and another account's 403, signed snapshot replay/tampering, CSRF/origin denial, attachment cache headers, authenticated French/Dutch labels and 16 concurrent alternating filtered requests with exact reference bytes. No API response mocks were used in those actual cases; two committed New UI failure/cancellation cases intentionally control transport to exercise those paths.
- One full local smoke/unit run: **10,304 passed, 103 skipped, 9 failed**. Two completed-locale failures were missing translations for an existing Export CSV anchor and were repaired; one hidden-book test mocked the old search seam and was updated with an actual-SQL hidden-visibility check retained. The remaining two metadata replacement SQLite I/O failures were already reproduced on clean main in this macOS harness; Linux PR CI remains a separate gate.

The first PR CI exposed a missed empty-result case: caliBlur’s decorative search-summary text intercepted clicks on export actions placed above the summary. The regression now submits a unique empty search and verifies a normal click downloads exactly the CSV header. It failed before the repair and passes at desktop and phone width after moving export actions below the heading and empty-result summary. No forced clicks or disabled pointer checks were introduced.
