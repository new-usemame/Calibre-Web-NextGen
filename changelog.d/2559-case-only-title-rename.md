### Fixed
- **Changing only the letter case of a title no longer deletes the book file.** On a case-insensitive library disk (default macOS APFS bind-mounted into the container, NTFS, exFAT, SMB), editing "The Folk of the Air trilogy" to "The Folk of the Air Trilogy" (by hand or by applying fetched metadata) treated the book's own file as a stale copy in the way and removed it, so the book kept its format listed but downloads returned 404. The folder and file are now renamed in place to the new case, and a genuinely different file at the destination is still replaced as before. Thanks to @jg120a for the report and the diagnosis.
