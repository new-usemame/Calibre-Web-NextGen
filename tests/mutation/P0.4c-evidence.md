## 2. Location-based loading

Both helper modules are resolved beside mutate.py, independently of sys.path.
The regression launches a fresh interpreter from another directory, loads mutate
by location, and reaches its container branch. It asserts neither helper is
already in sys.modules and supplies no Docker executable.

OBSERVED before the fix: the regression failed with
`ModuleNotFoundError: No module named 'container_backend'`.
After the fix it reaches the normal `ERROR: Docker CLI not found` message and
exit 2, exercising both container_backend and pytest_runtime loading without
using the container_module fixture. The full-suite results below include it.
