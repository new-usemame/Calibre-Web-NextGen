## Design limit

OBSERVED in the local macOS SDK sys/event.h: NOTE_FORK does not pass child PID to
userspace, and NOTE_TRACK/NOTE_TRACKERR/NOTE_CHILD have been unsupported since 10.5.
Consequently kqueue plus ancestry polling cannot establish arbitrary process-tree
ownership. Environment scans also cannot establish ownership after an exec with
a replaced environment. A fix must not call either mechanism a complete proof.
Filesystem scrub does not isolate temporary directories, the venv, common Git
data/config/refs, home directories, services, network, ports, or shared caches.

## Resolution — deliverable 2

OBSERVED: the kqueue tracker, launch gate, Linux token scanner, boolean liveness
probes, and stale-snapshot cleanup have been deleted. Recursive tracking cannot
be repaired by adding another ancestry poll. The diagnostic replacement reads
Darwin exec environments, takes repeated group/token snapshots, uses process
birth times to avoid knowingly signalling a reused PID, kills immediately, and
waits for process disappearance including zombies. The leader is reaped directly;
orphan descendants are reaped by the OS and observed gone.

OBSERVED: setup now consists of context-managed output files and Popen without
an extra pipe/thread/queue. Launch failure leaks no descriptors. Interruption
runs cleanup. Inspection errors reach containment_error and still attempt group
termination. Group permission failures are no longer swallowed. Unsupported
platforms and the default arbitrary-descendant contract reject before launch.

The diagnostic API requires explicit `ownership_contract="inherited-token"`.
This requires inspectable exec environments, unchanged user identity, and token
retention by descendants. It is NOT the requested arbitrary-descendant contract.
There is no permission inferred to weaken that requirement: the default stays
closed, and the existing command-line flow does not use this diagnostic backend.
The check-identity-then-signal syscall pair is not atomic; this too prevents a
claim of complete OS containment. A real kernel ownership boundary is still
needed to close deliverable 3 of this leg (parent deliverable 2).

OBSERVED: the original tests are replaced with readiness handshakes, actual PID
and zombie disappearance checks, an ignoring-SIGTERM child, interruption and
inspection-error exercises, descriptor-leak coverage, and a strict-mode rejection
test. A finite tokenless detached child is also executed as an explicit positive
counterexample to the diagnostic contract's completeness.

The original four tests had no trustworthy red history. After correction, the
exit, escape, and timeout tests have all been observed red with cleanup disabled
by a test-only fixture that restores real cleanup in its teardown. The poison
oracle has been observed red separately for all seven channels. Its bytecode
fixture reads generated bytecode, not cps or any project import; parent import
