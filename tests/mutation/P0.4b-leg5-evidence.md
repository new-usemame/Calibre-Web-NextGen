## 2. Git-writing policy — OBSERVED

Chosen policy: explicitly unsupported, documented in ISOLATION.md:3.
Source scanning cannot reliably detect dynamic Git commands or mutation-induced
writes, so no heuristic detection is claimed. Private HEAD/index changes are
scrubbed; shared refs/common config/hooks and other-worktree writes are unsupported.
Independent temporary repositories created by tests are allowed.

The test test_git_writing_policy_names_shared_state_and_demonstrates_limit
changes only its own synthetic repository. It writes a shared ref and common
config from its linked worktree, scrubs, and observes both changes still present.
