### Added

- **The new UI's Send to e-reader panel now has a tickbox for each saved address.** With several e-reader addresses saved, they arrived as one comma-separated string in the Recipient(s) field, so sending to just one meant deleting the rest by hand every time. Each saved address now gets its own tickbox, all ticked to start so the default is unchanged, and the free-text field stays for one-off recipients. With a single saved address the panel looks as before. Unticking every box disables Send rather than falling back to all saved addresses. Thanks to the reporter (#1763).
