# Interface font defaults

Administrators can choose separate default body and display fonts for accounts created after the setting is saved. The available values use the existing interface font presets; no font files are uploaded or installed. A blank value uses the active theme's built-in font.

These settings seed new accounts. They do not force a font on registered users: each person can change body and display fonts under **Account settings**. Changing an instance default does not update existing profiles. On a first install, the system Guest and initial admin rows are created before saved settings load, so they keep the built-in defaults; the Guest account is a system account and does not have a self-service profile.
