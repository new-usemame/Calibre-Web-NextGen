### Added

- **An administrator can start a user's My Library empty.** Switching an account to My Library used to fill it with every book it could see, so a new user who was meant to curate their own shelf began with the whole archive and no way to clear it in one step. The user's Library contents section now has a "Start My Library empty" option, shown in both the new and the classic admin pages (and as `start_empty` on the admin user API), that gives the account an empty library to add to from the global library. It is only offered when My Library is first enabled, and is refused for an account without the global-browse role (it could not add anything) and for an account that already syncs books to a Kobo (an empty set would remove them from the device). Part of #2352.
