### Fixed

- **The read icon on a caliBlur book cover no longer opens a reader that cannot show the book.** On a book whose only format is MOBI or AZW3, it opened a new tab with a "Not Found" error, even though the file was fine. Now clicking it on such a book does the same as clicking the rest of the cover and shows the book's details. For readable books it opens the same format as the detail page's "Read now", with EPUB preferred, and audiobooks still open the player. Reported and first fixed by @splitsec2 (#2249, #2250).
