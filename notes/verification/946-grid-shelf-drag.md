# Grid-to-sidebar shelf drag (#946)

The New UI lets a reader drag a book card to a writable ordinary shelf. Dragging a selected card snapshots the complete current selection; dragging another card carries that book alone. The sidebar and shelf list open for the drag without changing saved pin/collapse choices or moving the desktop grid. Touchscreens have a separate 44px pointer handle so ordinary card scrolling stays available. Tap or keyboard activation opens the same operation in a focus-trapped picker.

This is an add/copy operation: source shelf membership stays intact. Smart shelves remain rule-based and cannot receive drops. The existing server permission and library-membership checks remain authoritative. Four writes run at a time, every book receives an outcome, and only a genuine already-present membership conflict counts as success. Other HTTP409 errors remain failures. Partial failure shows server reasons, retains only failed books for retry, and cannot restore an old picker or selection after pathname or search navigation. Catalog bulk actions also block another shelf operation.

The catalog accumulator now consumes a successful refetch even when React Query preserves the returned object's identity. Verification exposed that an idempotent bulk action could otherwise clear the grid permanently. An obsolete source-count assertion was removed; executable accounting and browser outcomes cover this seam.

## Product choices and limits

A dedicated handle gives touch and keyboard users a reliable alternative without suppressing page scrolling. Automatic temporary sidebar expansion keeps the normal collapsed layout and makes lower shelves reachable. Existing per-book endpoints provide permission/error parity without adding a batch API, dependency or migration. Bounded writes avoid a20-request burst and preserve partial results. Membership is copied because removing the source shelf was not requested and would make a missed drop destructive.

The scoped feature is New UI drag-and-drop; Classic retains its existing shelf controls. A real iPhone physical drag, VoiceOver, a dedicated subpath deployment, and a published release image were not exercised here. Native iPhone WebKit picker behavior was exercised; trusted touch dragging was Chromium input, not an iPhone hardware claim. Local clone startup logs retain inherited malformed-book EPUB/backfill errors; they are not attributed to this shelf operation. Earlier desktop pre/post-drop timeouts and default-load navigation stalls are retained without an invented root-cause claim. Final assertions were not forced or retried. Release and deployment are separate.
