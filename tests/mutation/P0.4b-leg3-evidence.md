## 1. Import provenance — OBSERVED

`provenance_environment` prepends the canonical disposable root, preserves the
caller's environment, and resolves inherited relative PYTHONPATH entries before
cwd changes. `IsolatedSweep.run_phase` prepares this environment and requires
preflight before launching the requested phase. A rejection disables that sweep.

The pytest probe runs in real pytest collection context, with the phase's pytest
arguments when applicable, and checks after conftest/collection imports. The child
probe runs from a different cwd. The console probe executes the installed cps
launcher with its script-directory sys.path shape; a profile hook stops at entry
to cps.main.main before its application body. This is import-path verification,
not application startup verification. Canonical package file/spec/search paths
and the console main module must resolve within the tree. Reports use relative
paths; missing, failed, malformed and outside-root witnesses reject.

Command:
```sh
"$ROOT/repo/.venv/bin/python" -m pytest tests/unit/test_mutation_harness.py -k provenance -q -s -o addopts='' -p no:rerunfailures -p no:flaky --tb=short
```
