### Added
- **Clean up tags across the library from one page.** Admin > Metadata clean-up keeps a map of tag rules: rename a tag, split it into several, or drop it, matched regardless of case and accents. The page lists every book the rules would change, old tags next to new, and changes nothing until you apply. Each book is reported as changed, skipped (left out, or edited since the preview) or failed, the book files are updated when metadata enforcement is on, and an applied run can be undone from History. The map exports to JSON and imports back, so a cleanup can be shared or run again (Discussion #2481, #2438).
